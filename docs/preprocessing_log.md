# 전처리 기록

실행 순서: `src/preprocess/` 에서 `prep_spatial.py` → `prep_speed.py` → `prep_volume.py` → `prep_weather.py` → `prep_transit.py`
(`.venv/bin/python` 사용). 설정은 `config/config.yaml`. 품질 점검표는 `outputs/tables/quality_*.csv`.

## 공통 규칙
- **시간 기준 `hour_start`**: 모든 시간 데이터를 "해당 1시간의 시작 시각"으로 통일.
  - 소통정보 시간코드 `08`(`~8시`) = 07:00~08:00 → `hour_start = 7`
  - 기상 ASOS `tm 08:00` 강수 = 07:00~08:00 누적 → `hour_start = 7`
  - VolInfo `hh=08`, 승하차 `HR_8`, 스마트교차로 `STND_TM=0800` = 08:00~09:00 → `hour_start = 8` (명세상 시작 시각으로 가정)
- **첨두(`peak`)**: 원문 기준 출근 `hour_start` 8·9 (08~10시), 퇴근 17·18 (17~19시). 소통정보의 TOPIS 첨두 구분(`topis_peak`, T1=07~09시)은 비교용으로 원본 보존.
- **요일 구분(`day_type`)**: 평일/주말/공휴일. 공휴일은 한국천문연구원 특일 정보 API(대체·임시공휴일 포함, 2024~2026).
- **좌표계**: 분석 EPSG:5179(SGIS 경계와 동일). 표준노드링크 EPSG:5186, 교통량 지점·TOPIS 서비스링크 EPSG:5181(중부원점 FN 500000)로 판단 — 변환 후 서울 경계 안에 들어오는 것으로 검증.
- **결측**: 평균 대체 안 함. 아래 데이터별 처리 참고.
- **이상치**: 삭제하지 않고 플래그 컬럼으로 표시.

## 데이터별 처리

### 공간정보 (`prep_spatial.py`)
| 산출물 | 내용 |
|---|---|
| `seoul_gu.gpkg`, `seoul_dong.gpkg` | SGIS 2025년 2분기 경계에서 시도코드 11 추출. 자치구 25, 행정동 426 |
| `seoul_links.gpkg` | 표준노드링크(2026-10-14판) 중 서울 링크 63,411개, 중간점 기준 행정동/자치구 |
| `seoul_service_links.gpkg` | TOPIS 서비스링크 5,114개 형상(LinkVerInfo API) + 행정동/자치구 + 표준링크에서 이전한 차로수·제한속도 |

- **발견 사항**: 소통정보 링크ID는 국가 표준링크ID가 아닌 TOPIS 서비스링크ID → 직접 결합 시 70.5% 미매칭. 서비스링크 형상을 API로 받아 해결.
- 차로수·제한속도 이전: 서비스링크 15m 버퍼 안에 길이 50% 이상 포함 + 진행방향 코사인 > 0.7 인 표준링크의 길이가중 중앙값. 5,064/5,114개(99.0%) 매칭, 나머지 50개는 결측 유지.
- 서울 경계에 걸친 서비스링크 55개(1.1%)는 중간점이 서울 밖 → 자치구 결측 유지.

### 소통정보 (`prep_speed.py` → `speed_hourly.parquet`)
- 원본 2개 파일(루트 파일과 `manual/`의 동일 파일) → 키(기준일, 시간코드, 링크ID) 중복 168,719행 제거 → 168,719행.
- **기간: 2026-10-14 01:00 ~ 2026-10-15 09:00 (33시간, 평일 2일)**. 10-14 00시대 결측, 10-15는 10시까지만.
- 속도 결측 0. 이상치 플래그(`speed_outlier`: 0 이하 또는 제한속도×1.5 초과) 386행(0.23%).
- 혼잡 등급(`congestion`): 도시고속도로 <30 정체 / <70 서행, 그 외 <15 정체 / <25 서행 (config, 공식 기준 재확인 필요). 보조지표 `speed_ratio` = 속도/제한속도.

### 교통량 (`prep_volume.py`)
- VolInfo 차로별 44,150행 → 지점·시간·방향 합계 12,981행 (`volume_hourly.parquet`). 결측·중복 0.
- 139개 지점 중 9개는 시계(市界) 지점으로 서울 경계 밖 → 1km 이내 최근접 자치구로 매핑, `boundary_spot=True`.
- **기간: 2026-10-14 ~ 15** (소통정보와 동일 날짜만 수집).

### 스마트교차로 (`prep_volume.py` → `smart_intersection_hourly.parquet`)
- 다운로드 파일 20개가 각각 직전 11일을 포함해 겹침 → 88,523행 중 완전 중복 제거 후 11,804행. 같은 키에 다른 값 0건.
- **기간: 2026-09-19 ~ 10-18 (30일), 교차로 5곳(노원구 태릉·공릉 일대)** — 서울 전역 대표성 없음.

### 기상 (`prep_weather.py` → `weather_hourly.parquet`)
- 2024-01-01 ~ 2026-10-18, 24,528시간, 누락 0시간.
- 강수량 공란은 ASOS 무강수 표기 관례 → 0 처리, `rn_was_blank`로 원래 공란 여부 보존. 풍속 결측 0.13%는 그대로 둠.

### 지하철·버스 승하차 (`prep_transit.py`)
- 월 합계 자료 → 일평균(`daily_*`)은 월 일수로 나눈 값. **평일/주말 구분 불가**(원자료 한계).
- 지하철 538개 역 중 서울 밖 227개(자치구 결측 정상), 좌표 이름 매칭 실패 2개(평택지제, 한국항공대 — 서울 밖). 역명 변경 별칭: 당고개→불암산, 자양→뚝섬유원지.
- 버스 정류소 13,044개 중 2,379개 좌표 없음 — ID 앞자리 2xx(경기 정류소), 서울 정류소 좌표 API에 없음. 승차 인원 기준 4.96%.
- 버스 순환노선의 같은 정류소 재방문은 정류소명 순번으로 구분(키에 `stop_name` 포함). 잔여 중복 120행은 가상정류소(`(가상)`, 값 0).
- 가상정류소 `stop_id='~'` 144행.

## 핵심 한계
도로 속도 자료가 **33시간(평일 2일)** 뿐이라 월별·계절·요일·공휴일·강수 효과 분석과 AI 예측의 시계열 분할이 사실상 불가능하다.
더 긴 기간의 소통정보를 확보하는 것이 분석 품질에 가장 큰 영향을 준다.
